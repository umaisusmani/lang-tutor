# Lang Tutor

German conversation practice with an AI tutor. Chat in German at your CEFR level, get your grammar mistakes classified and explained, and keep track of what you get wrong.

**Live:** https://language-chatbot-starchy.vercel.app

## Stack

Next.js · TypeScript · Groq · Supabase (Postgres + Auth) · Vercel

## Run locally

```bash
npm install
cp .env.example .env.local   # add your keys
npm run dev
```

`npm run eval` runs the correction eval suite.
